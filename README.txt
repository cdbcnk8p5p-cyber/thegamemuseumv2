UPLOAD TO GITHUB PAGES
1. Extract this ZIP.
2. Upload every file and the complete assets folder to the root of the existing GitHub repository.
3. Replace the old files when prompted.
4. Commit the upload and wait a minute or two for GitHub Pages.
5. Refresh the live site. If the old version remains, close and reopen the installed app or refresh once more.
